# WhatAreThose

Swaps the item icons for the debug items `IceShoes` and `IceSkates` with custom art.

## Features

  * Replaces the `IceShoes` item icon with the included ice-spike art.
  * Replaces the `IceSkates` item icon with the included skate art.
  * No config, no recipes, no gameplay changes. The mod is client-side only.

## Notes

  * The mod only changes `ItemDrop.ItemData.SharedData.m_icons`, so it works wherever the items already exist.
  * Requires BepInEx.
